          About + Help

          About

          This is a full-stack stock "paper" trading simulator that lets you buy, sell, and analyze real-time stock market data using the Yahoo Finance API.
          It supports technical indicators, visualizations, portfolio tracking, limit/stop orders, and a persistent holdings storage system.
          The goal of this app is to enable individuals to practice trading strategieson the market with fake "paper" money, as well as perform basic stock analysis.
          Developer: Michael Bai

          Getting Started

          When you first load into the app, the default portfolio starts with $1,000 buying power and 1 share each of AAPL, AMZN, and GOOG.
          Try looking up prices, add a few symbols to your watchlist, then place a small buy or sell to see your P/L update in real time.

          Popular tickers to try:

          AAPL, MSFT, AMZN, GOOG, NVDA, TSLA, META, NFLX, BRK.B

          Tech Stack and Features

          • Frontend: HTML + CSS + JavaScript
          • Backend: Python (Flask)
          • Market Data API: yfinance (Yahoo! Finance)
          • Charts: Server-generated candlestick charts with overlays/indicators using Plotly Python
          • Persistence: Files portfolio.txt and watchlist.txt
          • Deployment: Render

          Stock Info Tab

          1. Stock Chart — Enter a valid ticker and view candlestick charts for 1d, 1w, 1m, 3m, 1y, or 5y, with:
            • MA10: 10-period simple moving average (near-term trend)
            • MA20: 20-period simple moving average (short/medium trend)
            • MA200: 200-period simple moving average (long-term trend)
            • RSI(14): 14-period Relative Strength Index (momentum). Values near 70 imply overbought; near 30 imply oversold.

          2. Price Lookup — Enter any valid ticker to see the current price and today’s percent change.

          3. Watchlist — Add/remove tickers to track. Each item shows live price and day % change. The list refreshes automatically every 15 seconds and persists in watchlist.txt.

          4. Buy / Sell — Shows current buying power. Enter a ticker and number of shares to place a market order (buy or sell shares).

          5. Place Limit / Stop Orders — Enter ticker, shares, and target price, then choose:
            • Limit Buy (LB): Buy only if price drops to or below your limit.
            • Stop Buy (SB): Buy once price rises to your stop price (buying for momentum)
            • Limit Sell (LS): Sell only if price rises to or above your limit (take profit).
            • Stop Loss (SL): Sell if price falls to your stop price (cap downside).

            The app checks for pending limit / stop orders every 15 seconds.

          My Portfolio Tab

          1. Deposit Funds — Add paper cash to your account balance (Fake Money).

          2. Deposit Funds — Remove paper cash from your account balance.
          3. P/L and Allocations — Shows total portfolio value, buying power, and total Profit/Loss (amount and %). Per holding: ticker, shares, value, allocation %, P/L, and P/L %.
          4. Holdings — Displays each position held in the format TICKER: X shares @ $Y (avg cost). Positions with zero shares are automatically removed.
          5. Transactions — Persistent log for BUY/SELL/DEPOSIT and executed limit/stop orders, including time, ticker, shares, and price.
          6. Pending Limit / Stop Orders — Any orders waiting to trigger.

          Save / Load Data tab

          Download or upload your data files. Filenames and formats must match:

          • Download — Get portfolio.txt (raw JSON) and watchlist.txt (plain text).
          • Upload — Restore state by importing the files:
            • Exact filenames required: portfolio.txt and watchlist.txt.
            • portfolio.txt: JSON (raw, unformatted is fine). Example: 
              {
  "holdings": { "AAPL": [5, 210.25], "MSFT": [2, 412.10] },
  "cash_balance": 1500.00,
  "transactions": [],
  "limit_orders": []
}
            • watchlist.txt: Tickers separated by newlines (standard) or any whitespace. Example: 
              AAPL
MSFT
GOOG
AMD

          Note: Uploads are validated. Invalid filenames or formats are rejected with an error message.
